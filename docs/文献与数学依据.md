## 累计梯形积分与相位分段

原始记录为 `x[l,c]`，长度为 `L≥2`，通道数为 6。累计梯形积分采用单位采样索引：

```text
A[0,c] = 0
A[l,c] = A[l−1,c] + (x[l−1,c] + x[l,c]) / 2
edge[k] = k·(L−1)/40，k=0,…,40
```

在累计积分的相邻采样索引间线性插值，得到 `A(edge[k],c)`，然后计算每段平均：

```text
r[k,c] = (A(edge[k+1],c) − A(edge[k],c)) · 40/(L−1)
```

这精确描述代码中的累计梯形积分及累计值插值规则。对于落在非整数索引的边界，不能未经检查就把它改成另一种连续信号插值或直接点采样，并声称仍是相同实现。

先从 40 步的每个通道减去该通道整段均值；再对加速度三轴、角速度三轴分别除以组 RMS。两组 RMS 的分母均为 `40×3`。不足 `1e-12` 的 RMS 使用 1 作除数。随后共享输入均值和样本 SD 只从当前训练记录的全部时间步计算，SD 使用 `ddof=1`，不足 `1e-12` 的 SD 置为 1。

## 固定投影、阈值和变化事件

标准化并裁剪后的输入为 `z[t]`，固定掩码为 `w_b`，阈值为 `θ_b`：

```text
bit_b[t] = 1{ z[t] · w_b > θ_b }
event_b[1] = 0
event_b[t] = bit_b[t] XOR bit_b[t−1]，t=2,…,40
```

54 路对应 6 个单轴单位向量，各使用 9 个 `[-0.8,0.8]` 等距阈值。其余 96 路由五个独立符号位生成 32 个 `(1,±1,±1,±1,±1,±1)/sqrt(6)` 投影，每个重复三个阈值 `[-0.3,0,0.3]`。这个编码是预设数字映射，不是由所引用论文或器件物理方程强制确定的映射。

XOR 的局部更新没有引用未来编码位；但全记录相位处理、去均值和 RMS 仍使用完整动作。两者需要分开描述，才能正确解释离线分类与在线处理的区别。

## 三指数递推与因果卷积等价

令 `d_j=exp(−Δ/τ_j)`、`a_j=exp(−δ/τ_j)`。每条动作开始前 `s_bj[0]=0`，递推为：

```text
s_bj[t] = d_j·s_bj[t−1] + g_j·event_b[t]
I_b[t]  = Σ_j a_j·s_bj[t]
```

逐次展开状态，可以得到：

```text
s_bj[t] = g_j · Σ_(k=1)^t d_j^(t−k)·event_b[k]
I_b[t]  = Σ_(k=1)^t h[t−k]·event_b[k]
h[q]    = Σ_j g_j·exp(−(qΔ+δ)/τ_j)，q≥0
```

这是从本项目更新式直接推导的因果卷积。代码可用递推实现，独立核验可按事件核求和实现；两者数值一致检查的是实现正确性，不是器件机理或分类优势的证明。

因为 `Δ>0`、`τ_j>0`，有 `0<d_j<1`。如果两个初态接收完全相同的后续事件，它们第 `j` 分量的差为 `d_j^t` 倍初始差，因此会衰减。对于有界二值输入，零初态分量也有上界 `g_j/(1−d_j)`。这些性质说明当前线性状态的稳定衰减与有限累积，不等于已证明任何任务的识别率、完整非线性 ESN 的性质或理论最大记忆容量。

## ADC 是独立的数字非线性

满量程为 `F>0`、位数为 `B≥1`，量化规则为：

```text
Q_B(I) = floor(clip(I/F,0,1)·(2^B−1) + 0.5) · F/(2^B−1)
```

本项目主设置 `B=2`、`F=3 nA`，所以可读等级为 `0、1、2、3 nA`。这解释了幅值较小的动态为什么可能在共同量程下落入同一档位。时间常数更长与量化后的信息可读性更高没有必然等价关系。

阈值、XOR 和 ADC 都会使从原始输入到最终特征的整体映射带有非线性，但状态递推对已编码事件仍是线性的。ADC 前的三指数卷积不能写成 `tanh` 动态，也没有支路间递归连接。当前流程不包含卷积神经网络的可训练卷积层。

## 展平特征与 Softmax 读出

每条动作的特征顺序为：

```text
f = [Q(I_1[1]), …, Q(I_1[40]),
     Q(I_2[1]), …, Q(I_2[40]), …,
     Q(I_150[1]), …, Q(I_150[40])]
```

特征均值 `μ_f` 与样本 SD `σ_f` 由训练部分拟合，零或极小 SD 置为 1。记标准化特征为 `v=(f−μ_f)/σ_f`，十类分数与概率为：

```text
score_c = v·W[:,c] + bias_c
p_c = exp(score_c) / Σ_a exp(score_a)
prediction = argmax_c score_c
```

训练目标与已审计实现的梯度对应：

```text
J(W,bias) = −(1/n)·Σ_i log p_(y_i)(v_i) + ||W||²/(2nC)
```

截距不作正则惩罚，读出训练使用多分类交叉熵；这不是给旧岭回归分数追加一个 Softmax 函数。L-BFGS 求解的收敛核验属于数值优化检查，不能被解释为泛化性能证明。

训练程序可在数值非零的完整训练线性张成空间中求解，再将读出权重还原到 6000 维。对于带 L2 惩罚的线性读出，训练特征张成空间之外的权重不能改善训练分数却会增加惩罚；因此这种坐标处理有数学依据。实现保留全部数值非零方向，没有按准确率挑选 PCA 维数；浮点截止与重建误差仍应记录。

## 评价结论需要来自本项目的证据

冻结动态和只训练读出说明了方法结构，不能自动证明器件增加了分类收益。公共结果需要结合嵌套受试者划分、每折训练缩放、预定候选范围和直接编码等对照理解。公开参考数据库此前已用于开发，模型电流也尚未构成任务硬件实测分类。

当前模型分类结果对读取位宽、统一量程和理想增益补偿敏感；直接编码基线尚未被定稿器件模型超过。因此适合报告固定条件下可复现的模型行为与差异，并保留 [科学表述与评价范围](科学表述与评价范围.md) 中的基线和限制。三篇文献提供方法背景，不替代这些本项目证据。
