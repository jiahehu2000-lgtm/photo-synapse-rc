# 复现与使用

本项目把六轴惯性动作记录转换成 40 步输入，经固定阈值编码、时间 XOR、冻结器件记忆模型及 ADC 量化，得到线性读出分类器的特征。器件电流由实测拟合参数模拟。训练代码使用仓库文件和命令行提供的数据目录，不依赖原研究电脑的绝对路径。

## 1. 在干净 Python 环境安装

以下命令均在本仓库根目录执行。以 Python 3.12 为例，先建立虚拟环境，按 `requirements.txt` 安装冻结运行依赖，再安装项目。精确 benchmark 优先使用这个流程：NumPy 2.4.6、SciPy 1.15.3、scikit-learn 1.7.2、threadpoolctl 3.6.0、joblib 1.5.2 与历史运行环境一致。`pyproject.toml` 中的版本范围便于常规安装，单独执行 `pip install -e .` 时可能得到其他版本。安装依赖通常需要联网；完成安装后，合成演示和本地数据计算均可离线运行。

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install --no-deps -e .
```

若 PowerShell 的执行策略限制环境激活，可以直接使用虚拟环境的 Python，无需修改系统执行策略：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install --no-deps -e .
.\.venv\Scripts\python.exe -m photo_synapse_rc --help
```

Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install --no-deps -e .
```

后面的 `python` 指已激活环境中的解释器。未激活时，Windows 可替换为 `.\.venv\Scripts\python.exe`，Linux 可替换为 `.venv/bin/python`。

## 2. 先运行无需外部数据的合成演示

Windows PowerShell 与 Linux 使用相同命令：

```text
python -m photo_synapse_rc demo --output outputs/demo
```

演示直接从程序生成的 `40 × 6` 输入开始，不联网下载数据，用于检查编码、器件电流和特征输出流程。原始惯性轨迹的重采样和记录标准化由下文的真实 MAT 数据命令执行。演示数据不是人体实测记录，不能用于报告真实动作识别准确率。

## 3. 下载并解压官方 UTD-MHAD 惯性数据

数据来自 [UTD-MHAD 官方页面](https://personal.utdallas.edu/~kehtar/UTD-MHAD.html)，惯性记录下载地址为 [Inertial.zip](https://personal.utdallas.edu/~kehtar/UTD-MAD/Inertial.zip)。可以通过浏览器下载，也可以使用以下命令。公共原始 MAT 不随本仓库打包。

Windows PowerShell：

```powershell
New-Item -ItemType Directory -Path data -Force
curl.exe --fail --location --output data/Inertial.zip "https://personal.utdallas.edu/~kehtar/UTD-MAD/Inertial.zip"
Expand-Archive -LiteralPath data/Inertial.zip -DestinationPath data/utd-mhad
Get-FileHash -LiteralPath data/Inertial.zip -Algorithm SHA256
```

Linux：

```bash
mkdir -p data
curl --fail --location --output data/Inertial.zip "https://personal.utdallas.edu/~kehtar/UTD-MAD/Inertial.zip"
unzip data/Inertial.zip -d data/utd-mhad
sha256sum data/Inertial.zip
```

冻结来源档案中的 ZIP 大小为 `5,344,156` 字节，SHA-256 为：

```text
1900de05775c04626dee30b34638b79dd739d481786f0a788f2fbb00663abea4
```

这是原始来源版本的核对值。若下载文件不同，应先检查官方数据版本及下载是否完整，再比较复现结果。

解压后通常得到 `data/utd-mhad/Inertial/a1_s1_t1_inertial.mat` 等文件。若已将原始数据放在其他磁盘或目录，只需将后续 `--inertial-dir` 改为相应路径；含空格的路径须加引号。

官方完整数据集包含 27 类动作、8 名受试者和 861 条有效记录，惯性采样率为 50 Hz。动作 1–21 的传感器位于右腕，动作 22–27 位于右大腿。本项目使用动作 1–10 的全部现存记录，均属于右腕数据。官方页面上的动作照片用于说明动作类别；代码输入仅为惯性 MAT 中的 `d_iner`，照片不进入储备池或读出分类器。[数据与传感器说明](https://personal.utdallas.edu/~kehtar/UTD-MHAD.html)

## 4. 精确读取 319 条公共记录

文件名 `aN_sN_tN_inertial.mat` 分别表示动作、受试者和重复编号。每个 MAT 必须有有限实数矩阵 `d_iner`，形状为 `N × 6`，前三列为加速度，后三列为角速度。预处理后输入形状为 `319 × 40 × 6`。

前十类的理想组合数为 320，但官方文件中缺少 `a8_s1_t4_inertial.mat`。因此第 8 类有 31 条，其余九类各有 32 条，总计 319 条。程序严格核对成员集合，不补造第 320 条。

`data/public_index.csv` 的 `file` 列确定记录顺序；可同时包含 `action_id`、`subject_id`、`trial_id`、`sample_count`、`channel_count` 等元数据。程序通过 `--inertial-dir` 找到实际文件，忽略历史索引中的 `source_path`。它拒绝缺文件、重复文件名、重复原始内容、非法矩阵以及与文件名或矩阵不一致的索引字段，并计算各原始文件的 SHA-256。索引中的 `sha256` 非空时，必须是 64 位小写十六进制字符串且与原始文件一致；省略索引时也会计算并保留文件哈希。省略 `--index` 时，按动作、受试者、重复编号进行数值排序；对照冻结结果时应使用仓库索引保持原记录顺序。

## 5. 运行公共数据 benchmark

Windows PowerShell 与 Linux：

```text
python -m photo_synapse_rc evaluate --inertial-dir data/utd-mhad/Inertial --index data/public_index.csv --output outputs/benchmark --method softmax
```

已有外部数据时，Windows 路径示例：

```powershell
python -m photo_synapse_rc evaluate --inertial-dir "D:/datasets/UTD-MHAD/Inertial" --index data/public_index.csv --output outputs/benchmark --method softmax
```

Linux 路径示例：

```bash
python -m photo_synapse_rc evaluate --inertial-dir "/path/to/UTD-MHAD/Inertial" --index data/public_index.csv --output outputs/benchmark --method softmax
```

默认同时计算 LIGHT 与 DARK，采用 2 位、0–3 nA 的模拟 ADC、150 路编码和 40 次读取，共 6000 个特征。两种条件分别训练读出，使用相同原始记录和分组规则。Softmax 为十类线性多项逻辑回归，采用 L2 正则化和 LBFGS 求解。

外层使用 8 折留一受试者验证；每折只在其余受试者内部进行三组按人划分的验证，重新拟合输入及特征标准化，选择正则化参数。测试受试者不参与本折选参。`evaluate` 输出逐折留出模型，仓库另提供此前使用全部319条公共记录训练的冻结部署模型。须区分按受试者等权平均准确率、319条汇总准确率以及部署训练分数；全部公共数据上的训练分数不能替代留一人验证结果。

这些公共记录此前已经用于方法开发，benchmark 属于历史公开数据复现。此处 ADC 位数是模拟设置，器件电流为冻结模型的输出。结果不能直接解释成实际硬件识别性能。

默认设置完成后，可核对638条光暗留出预测是否与保留结果一致：

```text
python scripts/verify_benchmark.py --output outputs/benchmark --method softmax
```

换读出时将评价命令的 `--method` 改为 `svm` 或 `ridge`，并使用新的输出目录。量化或无记忆对照可用 `--adc-bits 0`、`--reset-memory` 或 `--encoder-only`；减少读取用 `--reads`。这些改变会重新选参和训练，不能用默认方案的参考值代替它们的结果，默认参考核对脚本会拒绝这些设置。

## 6. 使用部署模型预测一个 MAT

Windows PowerShell 与 Linux：

```text
python -m photo_synapse_rc predict --model models/LIGHT_softmax_public319.npz --mat data/utd-mhad/Inertial/a1_s1_t1_inertial.mat
```

也可以把 `--mat` 改为其他符合上述 `d_iner` 格式的文件，把 `--model` 改为 `evaluate` 输出的 `outermodels` 中某个Softmax/SVM留出模型路径。模型包含标准化参数、固定编码、器件时间常数与增益、ADC设置、十类权重及偏置；预测时使用模型中的设置。SVM分数经过Softmax变换可用于显示相对分数，但不是经校准的概率。

该示例 MAT 属于训练公共数据库，用它可以检查加载和预测流程，不能把单条预测当作独立测试结果。手机、手表记录若要转换为这一格式，还需明确采样、时间对齐、单位和坐标约定；本命令不会自动替研究数据搜索坐标映射。

## 7. 运行数值单元测试

Windows PowerShell 与 Linux：

```text
python -m unittest discover -s tests -v
```

测试覆盖训练样本线性空间的 Gram 矩阵保持、标准化对验证数据的独立性、线性权重导出和 NPZ 重载、Softmax 概率归一化、Ridge 独立求解对照以及部分动作类别训练的拒绝行为。真实公共数据复现仍需另外执行上一节 benchmark，并核对其逐折输出。

## 8. 冻结器件参数与原始器件数据的边界

仓库提供 LIGHT、DARK 的冻结三指数拟合参数和运行代码，可直接计算状态与训练读出。完整原始器件实验记录未随仓库提供，因此当前可复现的是“给定冻结参数后的器件模型计算与公共动作 benchmark”，并非从全量器件原始数据重新拟合出这些参数。器件参数及有效模型适用范围应与方法说明一同引用，不能把三个时间常数直接当作已确认的三种物理机制。

UTD-MHAD 的推荐引用为：C. Chen, R. Jafari, N. Kehtarnavaz, *UTD-MHAD: A Multimodal Dataset for Human Action Recognition Utilizing a Depth Camera and a Wearable Inertial Sensor*, IEEE ICIP, 2015。[官方引用信息](https://personal.utdallas.edu/~kehtar/UTD-MHAD.html)
