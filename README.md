# PhotoSynapse-RC：光暗突触器件模型驱动的储备池计算

将本研究的非拉伸器件响应抽象为固定数学模型，用真实六轴动作信号驱动模型，训练最后的数字分类器，比较光照与暗态条件下的分类结果。本仓库提供可独立运行的 Python 代码、冻结参数、公开数据清单、公共数据库训练的部署模型及中文说明。

可以把它想成“水池与观察者”：输入刺激像连续落入水池的石头，衰减状态像尚未消失的波纹。这里的水池由器件测量校准的数学模型模拟；训练的是根据波纹判断动作的观察者，即读出分类器。

```mermaid
flowchart LR
    A["一次真实动作\n六轴惯性时序"] --> B["40步离线预处理\n40 × 6"]
    B --> C["固定投影与阈值\n150路时间XOR事件"]
    C --> D["冻结光照/暗态器件模型\n150路 · 450内部状态"]
    D --> E["共同2-bit读取\n150 × 40 = 6000特征"]
    E --> F["训练数字Softmax读出\n10个类别分数"]
    F --> G["输出动作标签"]
```

**结果来自器件模型驱动的仿真。** 器件核是独立线性三指数记忆模型，数字阈值、XOR 和量化提供端到端非线性。150 路支路没有相互递归连接；6000 是整段特征数。本实现不是 CNN，也不是随机递归 TANH 网络。

## 安装与快速运行

在 Python 3.12 虚拟环境中，从本仓库根目录运行：

```text
python -m pip install -r requirements.txt
python -m pip install --no-deps -e .
python -m photo_synapse_rc demo --output outputs/demo
python -m unittest discover -s tests -v
```

`demo` 完全离线，输出合成输入的光暗电流和6000维特征，明确不报告研究准确率。真实评价需另从 [UTD-MHAD 官方页面](https://personal.utdallas.edu/~kehtar/UTD-MHAD.html) 下载惯性 MAT：

```text
python -m photo_synapse_rc evaluate --inertial-dir data/utd-mhad --index data/public_index.csv --method softmax --output outputs/benchmark
python -m photo_synapse_rc predict --model models/LIGHT_softmax_public319.npz --mat data/utd-mhad/Inertial/a1_s1_t1_inertial.mat
```

`evaluate` 从头训练8折外层留一受试者和3组内层受试者验证，光暗各自选读出正则；保存全部预测、混淆矩阵、折内模型和训练审计。已存在的非空结果目录会被拒绝覆盖。`predict` 使用公共319条训练的最终部署模型；它的预测不能当作这319条记录的留出测试准确率。

## 定稿公共数据库参考结果

使用 UTD-MHAD 前十类的319条真实惯性记录、8名受试者、40步、150路编码、40次读取、共同2-bit／0—3 nA。主指标是8名外层留出受试者准确率的等权平均。

| 读出分类器 | 光照逐人平均 | 暗态逐人平均 | 光暗差值 | 光照正确条数 | 暗态正确条数 |
|---|---:|---:|---:|---:|---:|
| 岭回归 | 89.0064% | 66.1458% | 22.8606个百分点 | 284/319 | 211/319 |
| 线性 SVM | 88.0769% | 68.3333% | 19.7436个百分点 | 281/319 | 218/319 |
| 多分类 Softmax | 89.9439% | 65.5208% | 24.4231个百分点 | 287/319 | 209/319 |

这些记录此前用于开发，因此结果属于同一数据库重评价。共同低位数、绝对电流量程下的光照优势对幅值补偿和读取精度敏感；现有直接编码基线更高，尚未证明器件动态带来额外分类收益。完整控制结果和实测五动作整理历史见[评价范围](docs/科学表述与评价范围.md)。

## 代码与文件

```text
src/photo_synapse_rc/
  core.py             输入平均、固定编码、三指数模型、ADC、特征
  data.py             真实公共MAT读取与319条成员/哈希核验
  readout.py          训练内标准化、Softmax/SVM/岭回归
  evaluation.py       嵌套受试者验证与全部结果导出
  inference.py        冻结公共部署模型单条推断
  cli.py              demo / evaluate / predict
  resources/          光照与暗态冻结参数
data/public_index.csv 公开记录顺序与SHA256；原始MAT另行下载
models/               两套公共319条训练的Softmax部署权重
results/              历史参考、来源哈希与本次复现核验摘要
tests/                卷积、量化、编码、读出等数值验证
docs/                 中文方法与使用说明
```

冻结模型参数可用于完整 RC 流程复现。原器件校准原始曲线、私人手机／手表记录和完整 Origin 工程没有随仓库重新分发，因此本仓库没有声称可从未公开的原始器件测量重新拟合参数。仓库不修改原研究工程。
